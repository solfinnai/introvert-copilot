# Introvert Co-pilot

A networking co-pilot for introverts at conferences. Know yourself, know who to meet, know what to say, and follow up.

Built at Patch the Conference Hackathon (Oct 24 2026, San Francisco) with Bright Data, FalkorDB, TrueForge + OpenAI, and Qodo.

Sample conference: GitHub Universe 2026. Public sources only.
